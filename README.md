## 出處與著作權

- 書名：115 年度建教生手冊 勞動人權／勞動權益（A）（B）
- 出版者／著作財產權人：教育部國民及學前教育署
- 承辦單位：國立臺南高級商業職業學校
- 原始 PDF 公開於建教合作資訊網：https://cetw.k12ea.gov.tw/Cooperation/PDFArea
- 本站僅原樣呈現全書供瀏覽，未改作內容。

## 架構

純靜態翻頁電子書。`pdf/` 內的 PDF 由 GitHub Actions（`tools/build.py`，PyMuPDF）轉成頁面圖後部署到 GitHub Pages；標題與目錄設定在 `config.json`。
